What this check tells you

It checks whether OpenRouter accepts your key, whether the selected model is listed, and whether a small real generation request succeeds. It also displays latency, usage, errors, and quota headers when available. Provider quotas and pricing are not always exposed in response headers.

Important: this version uses an OpenRouter key, not arbitrary keys from Google, OpenAI, Groq, or other direct providers. One OpenRouter key can access models offered through OpenRouter, subject to each model's availability, pricing, credits, and account limits. Free-model availability can change.
